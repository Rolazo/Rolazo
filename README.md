# Nicolas Baena

**Building AI infrastructure for teams that move fast.**

I design and build the systems that make AI agents reliable, auditable, and scalable across organizations — from the first line of context to production automation running on AWS.

---

## Now

- Building **[baena-labs/ai-template](https://github.com/baena-labs/ai-template)** — an open governance system for Claude Code: agents, skills, hooks, and rules that sync across every repo in an org automatically
- Designing the **repo-split framework** — AI-driven decisions on when a domain needs one repo vs a family (`{domain}`, `{domain}-infra`, `{domain}-web`)
- Planning the **AWS migration** — moving org automation from local scripts to event-driven Lambda + ECS + Terraform, triggered by GitHub webhooks
